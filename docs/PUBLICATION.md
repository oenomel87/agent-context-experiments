# 선택 공개 범위와 변환

현재 공개 대상은 수정된 v4의 동질 이력과 교대 이력이다. 공개 관측1,970개는 완료1,930건·실패6건·차단34건을 포함한다. 이 가운데 전체 분석·채점 응답은1,078건이다. 교대가 참조하는 단건210개를 중복 저장하지 않는다.

## 포함

- 합성 원문20개와 중립 글1개, 루브릭, 역할 지침, 출력 스키마, 실제 job·세션 배정.
- 완료·실패·차단 상태, 원래 최종 응답의 분석·점수·이유, 실패 시 생성된 잘못된 ID 응답, 토큰 관측값·응답 시간.
- 원본과의 바이트 일치 여부를 로컬에서 확인한 반환 해시, 일관된 공급자 ID 별칭, 로컬 감사 요약.
- 오프라인 재계산·테스트·공개 범위 검사, 코드 원본 해시와 이식 내역.
- 중단으로 집계에서 제외된 완료3개 응답과 추가 시도 원장. 별도 파일이며 본 분석에 혼합하지 않는다.

공개한 응답·점수·사용량의 값은 원본과 동일하게 대조했다. 오류를 성공으로 바꾸거나 응답의 문장을 고치지 않았다. 순서·관계·합성 request/evaluation/job ID는 보존했다. 실제 공급자 thread/turn ID만 전역적으로 일관된 공개 별칭으로 바꿨다. 별칭 역매핑은 공개본 밖에 보관했다.

## 제외

인증정보, 개인 파일 경로, 타임스탬프가 포함된 원시 런타임 봉투, 개인 AGENTS.md, 원본 SDK/native 로그·숨은 reasoning, 실행 캐시·가상환경·설치 패키지·바이너리는 제외했다. 별도 개인 복구/실행 래퍼도 제외했다. 이전 설계의 결과는 Git 이력에 남기고 현재 연구 자료에서는 제거했다.

공개한 raw_response 필드는 실패한 A의 짧은 공개 JSON 최종 응답이다. 숨은 reasoning이나 raw SDK 로그를 뜻하지 않는다. 원문 인용문 자동 경고도 보존했다. 동질7개 응답의9개 구절, 교대11개 응답의11개 구절이며, 문장 축약인지 실제 근거 오류인지는 사람이 판단할 항목이다.

## 검증과 한계

공개본 검사에서는 금지 경로·자격 증명 형태·실제 공급자 ID, 파일 목록·해시, 관측 수, 설계와 기록 관계, 원래 응답 해시, 세션 별칭 관계, 점수 재계산, 전달 해시를 확인한다. 이는 모든 가능한 비밀이 없다는 보장이나 법적 권한 심사가 아니다. 로컬 감사 요약은 원본 로그를 독립적으로 인증하는 암호학적 증명이 아니다.

원래 결과를 이번 게시 작업에서 재채점하지 않았다. 라이선스는 소유자가 별도로 선택하지 않아 기존 미지정 상태를 유지했다. 기존 Git 이력을 보존하는 일반 커밋으로 교체한다.
