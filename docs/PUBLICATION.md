# 공개 범위와 편집 원칙

## 포함한 자료

1. **native:** 실제 세션을 유지한 단일·판정 분리 실험의 코드, 오프라인 테스트, 스키마, 설계, 합성 입력, 1,090개 선택 관측 전체와 집계.
2. **replay-fixed:** 수정된 사용자 평가 태도 자료를 사용한 단건/이전 글/이전 글+모델 평가 비교의 720개 선택 관측, 설계 배정, 입력과 오프라인 계산 코드.
3. **replay-cumulative:** 같은 자료 계열의 기록 재생 누적 비교 610개 선택 관측, 배정, 입력과 오프라인 계산 코드.
4. 선택 관측은 총2,420개다. 원래 모델 출력의 점수·이유·분석 내용은 값 단위로 그대로 보존했다. 실패를 성공으로 바꾸거나 점수가 좋은 행만 선택하지 않았다.

코드나 표 안의 user-stated100/70점과 모델이 평가한 논증 품질0–12점은 다른 값이다. 모든 사건·인물·수치는 합성이며 실존 개인의 인사평가 자료가 아니다.

## 제외한 자료와 이유

- 최초 보안 판정 실험과 초기 서두 표현 중심 실험: 연구 질문 및 자료 조작이 이번 공개 연구와 달라 첫 배포 범위에서 제외했다. 이들의 결과를 이번 결과에 합치지 않았다.
- 실패·복구 시도의 원본 로그: 개인정보성 운영 메타데이터와 실행 환경 정보가 포함돼 있어 공개하지 않는다. 실패·복구 횟수는 요약 원장에 남겼다.
- 원본 runs, SDK traces, native-evidence, snapshots, 개인 지침: 로컬 사용자 경로·원본 세션 정보가 포함된다. 원본 증거는 소유자가 별도 보존한다.
- 인증 파일, 가상환경, node_modules, SDK 바이너리, 패키지 캐시: 공개본에 복사하지 않았다. 설치 목록만 제공한다.
- 실제 공급자 thread/turn ID: 연구 내 관계가 유지되는 공개용 별칭으로 치환했다. 역매핑은 공개본 밖에 보존한다.

## 공개 관측의 변환

명시적으로 허용한 필드만 내보냈다: 설계 job ID, 역할·조건·위치, 완료 상태, 실제 출력, 토큰 사용량, 경과 시간, 모델명, 설계용 session key/turn 번호 및 인용 검사 플래그다. 제공된 경우 실제 thread/turn ID는 별칭으로 바꿨다. 원본 요청 파일 경로, 절대 trace 경로, source_path, 타임스탬프, 원시 SDK 결과와 시스템/개인 지침은 내보내지 않았다.

단위 테스트의 가상 응답은 테스트 코드에만 존재한다. 공개 관측표에 테스트 응답을 섞지 않았다. 관측표 재검산은 모델이나 로그인 없이 가능하다.

## 검증의 범위

공개된 verification-summary.json은 로컬에서 수행한 감사의 요약이다. 공개 관측과 배정으로 산술·행 수·별칭의 세션 연결은 검사할 수 있지만, 비공개 원본 SDK 대화가 공개되지 않았으므로 공급자 호출에 대한 외부 검증이나 암호학적 증명은 아니다.

Native 원래 자동 보고기는 cachewrite라는 키를 찾았지만 원본 필드는 cache_write_input_tokens다. 최종 reported-summary.json은 원본 필드의 관측값을 사용한다. 분석 인용의 문자 불일치5건은 원래 quality_checks 출력에 나타나지 않았지만 analysis_flags와최종집계에보존됐다. 해당 분석을 수정하거나 그 뒤 판정을 재채점하지 않았다.

## 이식 과정에서 바꾼 코드

- 개인 작업공간의 다른 실험 폴더를 참조하던 경로를 공개본 backend 및 data/source 경로로 변경했다.
- Python3.14 가상환경에 고정된 실행 파일 경로를 설치된 codex_cli_bin의 경로 조회로 변경했다.
- 라이브 호출은 EXPERIMENT_ENABLE_LIVE=1을 명시한 경우만 허용한다. 기본 재검산과 테스트는 오프라인이다.
- 실험의 채점 지침, 단계별 스키마, 입력 원문, 배정과 선택 관측의 점수는 바꾸지 않았다.

라이브 실행 코드는 기록된 런타임을 전제로 한 연구용 코드이며, 이식본으로 새 라이브 실험을 수행한 것은 아니다. 별도 사용자 환경에서 동일한 모델 접근과 출력까지 보장하지 않는다.
