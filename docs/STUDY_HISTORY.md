# 설계 변경 이력

## 이전 공개본

[초기 공개 커밋 eba5cc3](https://github.com/oenomel87/agent-context-experiments/tree/eba5cc3addd1e75aa8265d0155cd0800c74823c5)은 실제 세션 실험과 고정·누적 이력 재생 실험을 담았다. 실제 세션 멀티 조건은 지속 분석가가 만든 분석을 새 점수 판정가에게 전달하는 구조였다. 단건 평가에는 분석 단계가 없어 비교 과제에도 차이가 있었다.

그 결과는 해당 구조에 대한 관측이지만, 의도했던 ‘사용자 대화 담당 + 원문 분석·채점 전체를 수행하는 독립 평가자’ 구조의 증거로 사용할 수 없다. 지금 저장소의 표에 이전 점수9.90·11.70 등을 혼합하지 않는다. 재생 실험도 현재 실제 세션 연구와 합쳐 표본 수를 부풀리지 않는다.

## 현재 공개본: v4

A를 대화·위임·반환 담당으로, B를 현재 원문에 대한 전체 평가 담당으로 수정했다. S/B/I는 동일한 통합 분석·채점 과제를 수행한다. 실제 누적 세션과 새 단건 세션을 구분해 검증했고, 같은 기준선으로 동질 이력과 교대 이력을 실행했다.

현재 트리에는 이 두 실험과 재계산에 필요한 자료를 선택적으로 공개한다. 이전 내용은 Git 이력에 보존하고 현재 자료에서 제거했다. 이 교체는 과거 관측의 오류를 은폐하기 위한 기록 삭제나 Git 이력 재작성이 아니다.

2026-10-28~29(KST)에 실행한 두 실험의 중복 제거 배정은1,970개다. 단건 기준선210개는 한 번만 포함한다. 실패·차단·호스트 복구의 추가 시도는 별도 원장으로 공개한다.
