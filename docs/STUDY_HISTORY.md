# 연구 범위와 이전 시도

이 공개본은 작업 폴더 전체의 출판물이 아니다. 아래 구분은 결과의 좋고 나쁨이 아니라 연구 질문과 자료 조작의 일치 여부를 기준으로 한다.

| 단계 | 처리 |
|---|---|
| 초기 메일·외부 공개 보안 판정 실험 | 별도의 업무 행동 연구이므로 이번 글 평가 공개본에서는 제외 |
| 서두·맺음말의 따뜻함/냉정함만 바꾼 글 평가 | 사용자가 의도한 글 전체의 관대함·엄격함과 달라 연구 범위를 수정함. 이번 결론에 합산하지 않음 |
| 사용자 평가문 전체와100/85/70점이 담긴 수정 자료의 기록 재생 실험 | replay-fixed와replay-cumulative로 공개 |
| 같은 실제 세션에서 분석·판정을 누적한 실험과 판정 분리 조건 | native 주 연구로 공개 |
| 실제 세션과 대응 이력 재생을 직접 비교하는 보조 계획 | 설계만 존재하며 실행 결과로 제시하지 않음 |

앞선 수정 자료의 두 기록 재생 연구는 원래1,330개 배정이었다. 시스템 공백 관련 실패와 그 후속 차단을 보존한 뒤, 사용자가 승인한 복구에서 성공한 평가를 바꾸지 않고 미완료 배정을 처리했다. 최종1,330개 성공 관측을 선택했으며, 추가 실패30회를 포함한 실제 시도1,360회를 별도로 집계했다. 공개 관측표에 실패를0점으로 채우지 않았다.

Native 주 연구는 본 실험1,090회가 모두 완료됐으며 실패·재시도는 없었다. 별도 기술 점검10회는 관측표에 포함하지 않는다. 모델의 분석440개 중 인용 문자 불일치5개도 결과를 수정하지 않고 공개 관측에 남겼다.

모든 이전 원본과 실패 기록은 별도 보존한다. 이 공개본의 범위를 넘는 자료가 없다는 주장이나, 제외된 실험이 성공했다는 주장을 하지 않는다.
