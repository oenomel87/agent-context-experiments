# 역할·배정

[공통 실험 방법](../../docs/METHODS.md)과 data/plan.json, data/plan-sessions.json을 따른다. 현재 글의 원문 분석과 채점을 같은 evaluator 응답에서 수행한다. 같은 세션 S와 매번 새 B를 비교하며, A는 사용자 대화 유지·위임·반환을 담당한다.
