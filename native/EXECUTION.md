# 주 실험 실행 명세 — 2026-10-25

사용자가 Luna 주 실험1,090회와 실제 세션 사전 검증을 승인했다. 보조 실험은 실행하지 않는다. data/plan.json의I/S2/M2만 허용하고650개판정·440개분석 및470개논리세션을 검증한다. 프로토콜의 기존0–12점 글 논증 품질 과제를 유지한다.

기존 승인된 ChatGPT 로그인과 고정SDK/CLI0.159.3 어댑터를 재사용한다. OpenAI Docs의 [공식 SDK 설명](https://learn.chatgpt.com/docs/codex-sdk)은 같은 Thread에서 run을 다시 호출해 대화를 계속할 수 있음을 명시한다. 실제 세션 유지 여부는 문서만으로 판단하지 않고 로컬 원본 대화와 모델 응답으로 검증한다.

## 사전 점검

별도의 기술 자료로10회를 수행했다. 검증 표식의 두 번째 요청에 원래 표식을 넣지 않았는데도 같은 세션의 모델이 정확히 반환했다. 실제 분석·판정 스키마를 바꾸며 같은 세션4턴을 수행했고, 다른 구성에서는 분석가2턴과독립판정가2개의각1턴을 확인했다. 총5개thread의턴수는[1,1,2,2,4]다. 사전 점검 응답은 주 실험의점수나이력으로 사용하지 않는다.

증거는 runs/preflight-20261025-v1/에 보존했다. SDK 원본 rollout의 user 요청과 공개 assistant 최종 응답을 저장된 요청·응답과 순서대로 대조했다. 숨은 추론 텍스트는 내보내지 않았다. 실행 환경이 넣는 고정 AGENTS.md 사용자 지침이 초기 공통 전제로 확인됐으며 해시를 기록했다. 이 공통 지침은 실험 글이나 다른 조건의 결과가 아니며, 모든 주 실험 세션에서 동일한지 감사한다.

## 실제 세션 실행

동일 논리세션은 같은 SDK Session과Thread를 유지한다. S2는20개세션×22턴, M2분석가는20개세션×11턴, M2판정가는220개새세션×1턴, I는210개새세션×1턴이다. 세션의 마지막 응답 또는 실패 이후에만 어댑터를 닫는다. 현재 글과 현재 분석만 요청에 넣으며 이전 대화를 다시 직렬화하지 않는다.

루브릭은 공통 상위 지침에 있다. 요청의 필드 순서는 mode → current_analysis(있는경우) → current_submission이다. S2/M2의 같은 단계 지침과스키마는동일하다. 분석의원문인용불일치는분석품질표시로기록하고실제보고서를수정하지않는다. 스키마위반·2,000자분석상한초과는실패로보존하며해당native세션후속은차단한다.

전역동시6개, 같은세션동시요청금지, 세션준비30초, 응답90초, 자동재시도·형식수정0회다. 각순서블록안에서고정우선순위와의존성에따라준비된요청을실행하고블록을마친뒤다음블록으로이동한다. 실행중유휴절전방지를사용하지만모든시스템정지나시간공백을막는다고보장하지않는다.

현재실행기는부분native세션을새세션으로재생해재개하는것을거부한다. 같은세션정확복구가검증되지않은상태에서중단되면해당세션후속을차단한다. 재실행이필요하면별도시도에서대화전체를시작해야하며기존성공prefix와새대화를섞지않는다.

## 기록 및 감사

모든요청은모델접근전에문자열·스키마·지침해시와claim을저장한다. 각턴의실제thread/turn ID, SDK이벤트, 응답, 사용량을기록한다. 성공native세션은원본rollout의전체공개대화와실험요청을대조한다. 문맥압축·금지도구·모델변경·세션ID불일치는검출한다. SDK의내장도구목록이완전히비어있다고주장하지않는다.

파일·지침·원문·스키마·기존어댑터는시작전에snapshot과해시로고정한다. 원본에서설계용session_key와실제thread ID의연결을검증한다. 누적사용량은턴별차이이며별도세션을합산한다. 캐시입력/추론출력은각총량의부분집합이므로다시더하지않는다.

정답점수가없으므로단건대비차이와네조건의민감도를기술적으로비교한다. 주비교는중립글의관대−엄격차이를S2와M2에서대응시킨것이다. 서명있는평균과절댓값을함께보고하고실패·차단을0점으로대체하지않는다. 실제원화·달러청구액은관측하지않으면미관측으로남긴다.
